# Export Checklist (Template)

## F. Rahman & Brothers - Fertilizer Export Documentation

This checklist ensures all necessary documentation is prepared for export shipments.

### Required Documents

- [ ] **Buyer contract / Purchase Order**
  - Verify quantity, product specifications, and delivery terms
  - Confirm pricing and payment terms

- [ ] **Commercial Invoice** (3 copies minimum)
  - Complete product description
  - HS codes for all products
  - Unit prices and total value
  - Incoterms clearly stated

- [ ] **Packing List**
  - Number of packages
  - Weight (gross and net)
  - Dimensions of packages
  - Product batch numbers

- [ ] **Certificate of Origin**
  - Issued by authorized chamber of commerce
  - Matches invoice details

- [ ] **Phytosanitary / Health Certificate** (if required)
  - Check destination country requirements
  - Valid inspection certificate

- [ ] **Quality Certificate / Laboratory Report**
  - Product analysis results
  - Compliance with specifications
  - Batch testing documentation

- [ ] **MSDS / Specification Sheet**
  - Material Safety Data Sheet
  - Technical specification document
  - Handling and storage instructions

- [ ] **Bill of Lading / Airway Bill**
  - Ocean: Bill of Lading
  - Air: Airway Bill
  - Verify consignee details

- [ ] **Insurance Certificate** (if sold CIF/CIP)
  - Coverage amount matches invoice value
  - Valid for shipment route

### Import Documentation (Buyer Responsibility)

- [ ] **Import Permit** - Buyer must provide before shipment
- [ ] **Letter of Credit** (if applicable)
- [ ] **Bank details** for payment

### Additional Information

#### HS Codes & Tariff Classification
- **Urea (310210)**: Urea, whether or not in aqueous solution
- **TSP (310390)**: Mineral or chemical fertilizers, phosphatic
- **MOP (310420)**: Potassium chloride
- **DAP (310520)**: Mineral or chemical fertilizers with nitrogen and phosphorus

#### Incoterms Reference
- **FOB** (Free On Board): Seller delivers goods on board vessel
- **CIF** (Cost, Insurance, Freight): Seller pays freight and insurance to destination port
- **CFR** (Cost and Freight): Seller pays freight to destination port
- **EXW** (Ex Works): Buyer collects from seller's premises
- **FCA** (Free Carrier): Seller delivers to carrier nominated by buyer
